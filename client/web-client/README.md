# GateVision Admin Dashboard

AI-powered Automatic Barrier Gate System administration dashboard built with React, Vite, TypeScript, Tailwind CSS, shadcn-style UI primitives, and mock data only.

## Run

```bash
npm install
npm run dev
```

Build and tests:

```bash
npm run build
npm test
```

## Notes

- All data is simulated and stored in browser localStorage.
- No backend, authentication, camera stream, or AI inference is connected.
- Barrier gate and camera controls are mock actions only.
